# NOTEBOOKS

Here we keeps the notebooks used for experimentations like EDA or model trials.  

First you should go to `../data` and run the `DataFetcher.sh` script. After that, run the notebooks contained in this directory in the following order:  

* `data_preprocessing.ipynb`
* `sephora_data_preprocessing.ipynb`
* `EDA.ipynb`

The first two noteboks require the data to be downloaded by the script, while the last notebook expects the processed dataset produced by the second notebook.
